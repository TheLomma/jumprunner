# Jump Runner 🎮

Ein endloser Side-Scroller mit einer niedlichen Chibi-Spielfigur im blauen Anzug mit Zauberstab.

## Features
- Endloses Level mit steigender Geschwindigkeit
- 4 Hindernistypen: Kaktus, Box, Spike, Vogel
- Münzen sammeln
- Power-Ups: Schild, Zeitlupe, Magnet
- Doppelsprung
- 3 Leben
- Highscore

## Steuerung
| Taste | Aktion |
|-------|--------|
| Leertaste / ↑ / W | Springen |
| (zweimal) | Doppelsprung |
| ESC | Menü |
| R | Neustart |
| Tippen (Mobil) | Springen |

## Deployment (Vercel)

1. Repository auf GitHub pushen
2. Auf [vercel.com](https://vercel.com) einloggen
3. "New Project" → GitHub-Repo auswählen
4. Vercel erkennt die Konfiguration automatisch → **Deploy**

## PWA / Homescreen-Icon
Die App unterstützt PWA. Im Browser auf dem Smartphone:
- iOS Safari: Teilen → "Zum Home-Bildschirm"
- Android Chrome: Menü → "Zum Startbildschirm hinzufügen"
